# Contributing

For now, send photos, menu descriptions, or tasting notes to the curator for collaborative reconstruction in ChatGPT. Original videos are used for analysis only and are not stored in this repository.

Keep **observations** (what was actually seen or tasted) separate from **recipe estimates**. Do not present speculative measurements as verified. Recipes progress from `draft` to `ready-to-test` to `verified` after home testing. Do not commit personal information or unlicensed third-party media.

Recipes are stored as entries in `data/recipes.json`. The generated catalog reads this file directly. Contributors can propose changes via pull requests later.
